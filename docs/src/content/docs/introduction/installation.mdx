## Entry points

| Import | Use it for |
| --- | --- |
| `di-craft` | Tokens, providers, containers, scopes, and annotations |
| `di-craft/node` | Async request scopes backed by `AsyncLocalStorage` |
| `di-craft/next/server` | Next.js App Router server composition |
| `di-craft/next/client` | Hydrating serializable client state |

<Aside type="note" title="Keep server code server-only">
	Import the Node and Next server entry points only from server modules. The
	client adapter intentionally contains hydration helpers—not a server container.
</Aside>
