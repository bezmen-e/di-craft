In this tutorial, you will define typed dependencies, connect them with
providers, and resolve a service from a container. You only need a TypeScript
project and the package installed.

<Steps>

1. Define typed tokens

   A token is a unique runtime key that also carries the TypeScript type of its
   value.

   ```ts
   const CONFIG = createToken<Config>("CONFIG");
   const LOGGER = createToken<Logger>("LOGGER");
   const USERS = createToken<UserService>("USERS");
   ```

2. Describe construction with providers

   Use a value provider for existing values and a factory provider for services.
   Dependency names are inferred in `useFactory`.

   ```ts
   provideValue(CONFIG, { logPrefix: "users" });

   provideFactory(LOGGER, {
     deps: { config: CONFIG },
     useFactory: ({ config }) => new Logger(config.logPrefix),
   });
   ```

3. Create a container and resolve at the edge

   ```ts
   const container = createContainer(providers);
   const users = container.get(USERS);
   ```

</Steps>

<Aside type="tip" title="Keep the container at the composition root">
	Inject the resolved dependencies into domain code. Passing the container itself
	through the application hides dependencies and turns injection into service
	location.
</Aside>
